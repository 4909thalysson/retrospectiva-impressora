Data de divulgação

Configure a data uma vez em GI_RETROSPECTIVE_RELEASE_AT, no arquivo config-publico.js, e publique a alteração. Todos os dispositivos mostrarão a mesma contagem.

QR Code da retrospectiva.

Gere um QR Code geral para a página de acesso ou selecione um colaborador para criar um QR individual, com o código já preenchido.

O endereço é preenchido automaticamente com base na hospedagem da Central. Se necessário, ajuste GI_PUBLIC_ACCESS_URL no arquivo config-publico.js. Selecione um colaborador para incluir o código no QR e exibi-lo abaixo da imagem.
